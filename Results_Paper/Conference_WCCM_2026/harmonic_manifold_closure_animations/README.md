# Harmonic manifold closure animations

This folder contains self-contained Python scripts for generating the manifold
animations used to explain linear, piecewise linear, quadratic, POD-AE, and
ANN/RBF/GPR-style closure models on a controlled harmonic benchmark.

The scripts do not read external simulation data. Each animation is generated
from the synthetic trajectory defined in `benchmark.py`, then written to the
`outputs/` folder.

## Quick start

From this repository:

```bash
cd Project_YvonMaday/Results_Paper/harmonic_manifold_closure_animations
python3 render_all.py
```

This regenerates all currently supported GIF animations in `outputs/`.

To render only one animation, run its script directly. For example:

```bash
python3 quadratic_manifold.py
python3 nonlinear_closure_manifold.py
python3 local_prom_ann_two_bases.py
```

## Python and system requirements

The scripts use:

- Python 3
- `numpy`
- `scipy`
- `matplotlib`
- `pillow`
- `torch` for `pod_ae_manifold.py` only
- A LaTeX installation with `amsmath`, because `animation.py` sets
  `matplotlib` to use LaTeX text rendering

If LaTeX is not installed, either install a TeX distribution or temporarily set
`"text.usetex": False` in `animation.py`. The latter changes the typography but
does not change the benchmark or the animation logic.

## What the benchmark represents

The controlled trajectory is

```text
u(t) = [q1(t), q2(t), 0.40 cos(2t) + 0.06 sin(3t)]^T
q1(t) = cos(t)
q2(t) = sin(t)
```

In harmonic coordinates, the third component can be written as

```text
u3 = 0.40 (q1^2 - q2^2) + 0.06 (3 q2 - 4 q2^3)
```

The second harmonic is exactly quadratic in `(q1, q2)`. The third harmonic is
cubic, so a purely quadratic manifold cannot reproduce it exactly. This makes
the benchmark useful for comparing:

- a global linear POD manifold,
- local/piecewise linear approximations,
- a quadratic manifold,
- a general nonlinear closure represented visually as ANN/RBF/GPR,
- a POD-AE latent decoder manifold.

The actual animation coordinates are POD coordinates, not the original harmonic
coordinates. The benchmark builds an affine reference and a rank-two POD basis:

```text
u_ref = u(0)
q_POD = V^T (u - u_ref)
```

The shifted snapshots are decomposed by SVD. The retained basis `V` has two
columns, and the discarded complement `V_bar` is used by the closure examples.

## Main notation

The animation labels use the following model forms:

```text
linear:      u_ref + V q
quadratic:   u_ref + V q + H h2(q)
closure:     u_ref + V q + V_bar F(q, mu, t),  F in {N, M, H}
POD-AE:      u_ref + V_tot D_AE(z)
```

Here `h2(q)` contains the quadratic monomials, `F` denotes a learned closure
map, and `D_AE` is the decoder of a coefficient-space autoencoder.

| `benchmark.py` | Builds the synthetic trajectory, POD basis, quadratic features, closure coordinate, and relative-error helper. |

| `quadratic_manifold.py` | Fits and renders the quadratic manifold `u_ref + V q + H h2(q)`. |
| `nonlinear_closure_manifold.py` | Uses an RBF interpolant as one concrete visual realization of a general ANN/RBF/GPR closure map. |
| `generic_decoder_tangent.py` | Shows a nonlinear decoder manifold, a moving point, the local tangent plane, and tangent basis vectors. |
| `pod_ae_manifold.py` | Trains a small coefficient-space autoencoder and renders its decoded latent manifold. |
| `aggressive_compression_cases.py` | Shared implementation for the three one-mode closure/multiplicity cases. |
| `case1_state_closure.py` | Case 1: closure as `q_bar = N(q)`. |
| `case2_parameter_time_closure.py` | Case 2: closure as `q_bar = M(mu, t)`. |
| `case3_hybrid_closure.py` | Case 3: closure as `q_bar = H(q, mu, t)`. |
| `local_prom_ann_two_bases.py` | Renders separate local linear POD, global ANN/RBF/GPR, and two-chart local nonlinear closure assets on a continuous multi-peak manifold. |
| `render_all.py` | Runs all supported animation scripts in sequence. |

## Interpreting the main animations

`linear_manifold.gif` shows the rank-two affine POD plane. It captures the main
projection but misses the nonlinear out-of-plane coordinate.

`piecewise_linear_manifold.gif` shows that local linear models can improve the
geometric approximation by covering different regions with different tangent
planes, but the representation remains locally affine.

`quadratic_manifold.gif` shows the quadratic correction. It captures the
second-harmonic structure but cannot fully represent the third-harmonic term.

`general_ann_rbf_gpr_closure.gif` shows the more general closure form
`V_bar F(q, mu, t)`. The current script uses an RBF interpolant only as a
deterministic drawing device; the slide meaning is method-neutral and applies
to ANN, RBF, or GPR closures.

`pod_ae_manifold.gif` trains a small autoencoder in coefficient space with
`n_tot = 3` and latent dimension `n_z = 2`. Its decoder defines the latent trial
manifold

```text
u_tilde = u_ref + V_tot D_AE(z)
```

`generic_decoder_tangent.gif` is not a closure comparison. It illustrates a
generic nonlinear decoder, the tangent plane at a point on the manifold, and the
two local tangent directions.

## Aggressive compression cases

The Cases 1-3 animations intentionally retain only one POD mode:

```text
dim(V) = 1
dim(V_bar) = 2
```

They compare three possible closure inputs:

```text
Case 1: q_bar = N(q)
Case 2: q_bar = M(mu, t)
Case 3: q_bar = H(q, mu, t)
```

Case 1 exposes multiplicity: the same retained coordinate `q` can correspond to
different discarded coordinates. Cases 2 and 3 add branch-identifying
information through parameter/time or hybrid inputs. This point is independent
of whether the deterministic regressor is implemented as ANN, RBF, or GPR.
